# Cosmos Gallery

Galeria de imagens do espaço: pesquise por termos como Lua, Marte,
nebulosas e galáxias, e veja os detalhes de cada imagem. Usa dados
reais da NASA Image and Video Library API.

## Integrantes

## API utilizada
NASA Image and Video Library API: https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf

## Tecnologias
HTML5, CSS, JavaScript (sem frameworks).
